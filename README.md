# Option-pricing-project
Black-Scholes pricing of European options, Greeks derived analytically, Monte Carlo valuation compared to Black-Scholes valuation, with an implied volatility surface built from real SPY options data.

# Features
Black-Scholes pricer for European option with put-call parity verification.

Greeks derived analytically (Delta, Gamma, Vega, Rho, Theta)

Vectorised Monte Carlo pricer and convergence analysis with Black-scholes

Visualisations of Greeks against spot and expiry

Implied volatility backsolved and IV smile and surface plotted for real SPY data
